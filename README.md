# Noor Al-Huda (نور الهدى) - Flutter Application

A serene, complete Islamic companion Flutter application featuring Prayer Times, Quran Reader with audio, Qibla Compass, Digital Tasbih, and Hisn al-Muslim Azkar.

## 🚀 Quick Start Guide

```bash
# 1. Ensure Flutter 3.x is installed
flutter --version

# 2. Navigate to project directory
cd noor_al_huda

# 3. Get dependencies
flutter pub get

# 4. Run on connected phone, simulator, or web
flutter run

# 5. Build production APK
flutter build apk --release
```

## 📦 Key Dependencies
- `adhan`: Accurate astronomical Islamic prayer times calculations
- `google_fonts`: Arabic Amiri and modern Plus Jakarta Sans typography
- `flutter_compass`: Magnetometer sensor compass for Qibla direction
- `vibration`: Tactile haptic feedback for Tasbih and Qibla alignment
- `just_audio`: High quality Quran recitation streaming
